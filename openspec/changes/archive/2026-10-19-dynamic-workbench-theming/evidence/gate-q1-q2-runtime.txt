## Static facts (4.40 bytecode, javap of the installed bundles; not runtime)
- org.eclipse.ui.internal.dialogs.ViewsPreferencePage (Appearance): the theme combo input is IThemeEngine.getThemes() unfiltered
  (no hidden/visibility check). The extension schema org.eclipse.e4.ui.css.swt.theme `theme` element has only
  id, label, basestylesheeturi, os, ws, os_version. os/ws/os_version remove an entry from getThemes() entirely, so they cannot hide a
  selectable twin on the same platform. => no supported way to hide a twin.
- org.eclipse.ui.internal.themes.ThemeElementHelper.installColor: when ColorDefinition.isEditable() is false the registry receives the
  definition default, never the stored preference value.
- ColorsAndFontsPreferencePage$ThemeContentProvider skips ColorDefinition/FontDefinition with isEditable() == false
  (not listed on the Colors and Fonts page).
- No themeAssociation element in the 4.40 theme bundle plugin.xml: switching a CSS theme does not change the Colors-and-Fonts theme.
